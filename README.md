# 🏫 M.S. Public School - Enterprise ERP System

A complete, secure, and modern School Enterprise Resource Planning (ERP) system designed to digitize and automate daily school operations.

**Owned & Maintained by:** M.S. Public School  
**Contact:** shubhampatel8694 (GitHub)

## 🚀 Key Features
* **Role-Based Access Control (RBAC):** Secure login portals for Admin, Teachers, and Students.
* **Fee Management Engine:** Advanced dynamic fee calculation (Tuition, Transport, English Medium Extra), advance tracking, and A5 PDF receipt generation.
* **Exam & Result Module:** Excel-style bulk marks entry, auto-grading, dynamic timetable setup, and automated A4 Report Card & Hagaki Admit Card generation.
* **Cloud Database & Auto-Heal:** Powered by PostgreSQL (Supabase) with automated table initialization and healing mechanisms.
* **Responsive UI/UX:** Custom 3D CSS rendering and mobile-responsive collapsible navigation.
* **Advanced Analytics:** Real-time financial dashboards and class-wise performance tracking using Plotly.

## 💻 Tech Stack
* **Frontend:** Python, Streamlit, Custom HTML/CSS
* **Backend / Database:** PostgreSQL (Supabase), psycopg2, SQLAlchemy
* **Data Processing:** Pandas
* **Data Visualization:** Plotly Express
